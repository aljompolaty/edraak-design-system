تشغيل اختبار Flutter على GitHub — خطوة بخطوة

المدة المتوقعة: حوالي 10 دقائق. لا تحتاج إلى تثبيت أي برنامج على جهازك، كل شيء يتم في المتصفح.

الخطوة 1

إنشاء حساب GitHub ومستودع جديد

إذا لم يكن لديك حساب، أنشئ واحداً من github.com. ثم اضغط زر + أعلى الصفحة واختر New repository.

اختر Private حتى لا يكون المشروع علنياً. اسم المستودع حر، لكن استخدم edraak-design-system لتسهيل المتابعة.
الخطوة 2

ترتيب الملفات على جهازك

تأكد أن مجلد edraak-design-system الذي تسلّمته يبدو هكذا:

edraak-design-system/
├── edraak-design-system.html
├── manifest.json
├── tokens.css
├── tailwind.config.js
├── fonts/
├── logo/
├── icons/
├── social/
├── flutter/
│   ├── edraak_theme.dart
│   ├── edraak_theme_test.dart
│   ├── edraak_pubspec_fonts.yaml
│   └── ci/
│       └── flutter-theme-check.yml   ← ملف الاختبار الآلي
└── guide/
لا تغيّر أسماء الملفات أو أماكنها، لأن سير العمل يبحث عنها بهذه الأسماء بالضبط.
الخطوة 3

رفع المجلد إلى المستودع

  1. من صفحة المستودع الجديد، اضغط uploading an existing file أو Add file ← Upload files.
  2. اسحب محتويات مجلد edraak-design-system (كل الملفات والمجلدات داخله، وليس المجلد نفسه) إلى المنطقة المخصصة.
  3. انتظر حتى تكتمل قائمة الرفع، ثم اكتب رسالة قصيرة مثل Initial upload.
  4. اضغط Commit changes.
الخطوة 4

إنشاء ملف سير العمل داخل GitHub

هذه الخطوة تنقل ملف الاختبار الآلي إلى المكان الذي يبحث فيه GitHub.

  1. اضغط Add file ← Create new file.
  2. في خانة اسم الملف اكتب بالضبط:
    .github/workflows/flutter-theme-check.yml
    عند كتابة الشرطة المائلة / ينشئ GitHub المجلدات تلقائياً.
  3. افتح على جهازك الملف flutter/ci/flutter-theme-check.yml بمحرر نصوص (مثل Notepad)، وانسخ كل محتواه.
  4. الصقه في منطقة المحتوى الكبيرة.
  5. اضغط Commit changes.
انتبه: النقطة في أول الاسم مهمة. إذا ظهر الملف في مكان آخر فالمسار غير صحيح.
الخطوة 5

تشغيل الاختبار ومتابعة النتيجة

  1. من أعلى المستودع اختر تبويب Actions.
  2. إذا طُلب منك تفعيل سير العمل فاضغط I understand my workflows, go ahead and enable them.
  3. سيبدأ التشغيل تلقائياً بعد حفظ الملف. إذا لم يبدأ، اختر الاسم Edraak theme check من القائمة الجانبية ثم اضغط Run workflow.
  4. انتظر بضع دقائق (أول مرة تكون أطول لأنه يحمّل Flutter).
النجاح: كل الخطوات بعلامة ✓ خضراء. الفشل: اضغط على الخطوة الحمراء، وانسخ السطر الذي يحوي كلمة error وأرسله لي.
الخطوة 6

إذا فشل التشغيل: ماذا أرسل لي؟

  1. افتح الخطوة الفاشلة واضغط عليها.
  2. انسخ آخر 30 سطراً تقريباً من السجل، وخاصة الأسطر التي تحتوي error أو Error.
  3. أرسلها لي مع اسم الخطوة الفاشلة، وسأعدّل الملفات وأعطيك نسخة محدّثة للرفع.
